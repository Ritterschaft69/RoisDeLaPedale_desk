# Raccords des épaules et des hanches

Télécharger **RoisDeLaPedale-0.5.1-Setup.exe** ci-dessous.

- Le torse, les épaules et les manches forment désormais un seul maillage lissé. Le volume des deltoïdes est raccordé au maillot, sans bouchon de cylindre superposé.
- Le bassin et les deux jambes du cuissard forment également une surface unique. Un squelette à trois os déforme progressivement les hanches pendant le pédalage ; chaque bas de cuissard suit sa propre cuisse.
- Six nouveaux contrôles vérifient la continuité des surfaces, les poids d’animation et les raccords pendant un tour complet. 148 contrôles réussis au total.

Installeur Windows construit par GitHub Actions ; installation et exécution sous Windows non testées dans ce cloud Linux.
